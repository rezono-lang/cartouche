# Decision 0003: Six Breathing Atlas Sheets and One Unified @rezono/slip Backbone

## Context
Attempting to weld 11 epistemic instruments into a single viewport creates visual congestion. Cartographic clarity requires one calm primary argument per sheet paired with one consistent proof drawer.

## Decision
1. Cartouche ships **six domain-neutral Sheet Archetypes**, each focused on one primary question:
   - `01` `relief-3d`: 3D Swisstopo Statutory Relief (+ 2D profile fallback)
   - `02` `flow-split`: Flow & Reality-Split Curtain (`stated ∥ observed`)
   - `03` `kringstand`: Control-loop Board (`needed / waiting / ready / done / absent ⦸` + separate hatched `unknown ▨` strip + `<250ms` live lock)
   - `04` `causal-ripple`: Adaptive Distance Columns (>12 nodes) & Live Causal Ripple Graph (`OR`-shields vs `AND` load-bearing cliffs)
   - `05` `bitemporal-stair`: 2D Matrix ↔ 3D Orthographic Bitemporal Staircase (`Valid Time × Knowledge Time`, hollow `– N/A`)
   - `06` `monge-fold`: Monge Orthographic Folding Atlas (`0° flat 2D ↔ 90° 3D prism`, 4D with zero perspective distortion)
2. Every sheet shares ONE collapsible **`@rezono/slip`** proof drawer housing:
   - The compact 5-bar micro **Epistemic Prism**,
   - The 6 keyboard-bound Rezono verbs (`w d m s c p`),
   - Ranked **Certainty Levers** under `[M] Missing`,
   - **`Δ = 1` Adjacent Worlds** under `[S] Suppose`, and
   - Automatic physical lock on `[P] Propose` whenever the 3-tier Cartouche seal is `provisional_engine`.
3. Every sheet includes an auto-generated Legend (only drawn signs), a 3-tier Cartouche Corner Seal, and a synchronized accessible HTML Table Twin.
